DIANPING SCRAPER GUIDE

大众点评评论抓取工具 · 使用说明

三步把一家门店的全部评论（含商家回复）变成一张 Excel 能直接打开的表格

版本 2.0.0 平台 Windows 需要 电脑版微信 + 大众点评小程序 全程约 10–30 分钟
01

这个工具能做什么

在电脑版微信里打开大众点评小程序，工具会一边自动翻动评论列表，一边把翻过的评论全部记录下来，最后整理成一张 CSV 表格。每条评论包含：评论人、日期、评分、人均消费、评论内容、情感分类（好评/中评/差评），以及商家的回复。

你只需要做一件事：在工具开始运行后，用鼠标在微信里把目标门店的评论列表页打开。剩下的滚动、记录、停止、恢复网络，全部自动完成。

02

开始之前，确认两件事

  • 这是一台 Windows 电脑，并且电脑版微信已登录，能在微信里打开大众点评小程序（搜「大众点评」即可）。
  • 第一次在这台电脑上用，需要先由管理员运行一次 dianping_scraper.exe 同目录下的 setup_env.ps1（装 Python、抓包组件和证书，只需一次）。之后每次使用直接按下面三步走。
怎么打开命令行
打开 dianping_scraper.exe 所在的文件夹，点击顶部地址栏，输入 cmd 后回车——命令行窗口会直接停在这个目录，接下来所有命令都在这里输入。
03

使用流程：三步走

STEP 1
检查环境
跑一条命令，5 项检查全部通过即可继续
STEP 2 · 需要你配合
抓取评论
你打开评论列表页，工具自动滚动抓取
STEP 3
导出表格
一条命令，得到 CSV 文件，Excel 直接打开

整个流程只有第二步需要人在场配合，其余两步各跑一条命令即可。

第一步：检查环境

命令行输入
>dianping_scraper.exe check-env

会逐行检查 Python、抓包组件、证书等 5 项，每项显示 ok、最后一行 ready : True 就可以进入第二步；出现 NOT FOUND / MISSING 就找管理员重新运行 setup_env.ps1。

第二步：抓取评论人在场配合

门店名随便写（用于显示），门店ID向需求方索取（它决定文件名，同一个店每次要用同一个ID）。命令跑起来之后，按下面的顺序操作：

命令行输入（示例：抓“丰裕(淮海店)”）
>dianping_scraper.exe capture "丰裕(淮海店)" 080501 :: 门店ID 换成实际编号；默认一直抓到评论翻完为止
  • 命令运行后，打开评论列表页
    在电脑版微信进入大众点评小程序 → 搜索门店 → 点开门店 → 进入评论列表页（点「全部」或「最新」评论均可）。窗口会提示等待，180 秒内完成这一步，超时需重新运行命令。
  • 进入列表页后，松手
    工具检测到页面加载后会自动接管鼠标滚动，此时不要碰鼠标和键盘，等它翻完整个列表。期间命令行会显示进度（已抓条数）。
  • 想要商家回复的「时间」？点开几条评论
    商家回复的内容只滚列表就能全部抓到；但回复的时间只有在抓取期间点开几条带「商家回应」的评论详情页才能补上。不需要时间就可以完全不管。
  • 工具自动停止
    翻到评论列表底部（或达到设定条数）会自动停止，并自动恢复网络。命令行显示 capture finished 即完成，数据保存在 门店ID_capture.jsonl。
注意
抓取期间工具会临时开启系统代理，结束时无论成功、失败还是中途按 Ctrl+C，都会自动关闭代理恢复网络，不需要手动处理。

第三步：导出表格全自动

命令行输入（示例）
>dianping_scraper.exe export 080501 --org-code 080501 --store-name "丰裕(淮海店)" :: org-code 和 store-name 会写进表格，向需求方确认后填写

几秒钟完成，在当前文件夹生成 080501_reviews.csv，双击即可用 Excel 打开（已处理编码，不会乱码）。命令行最后会显示总条数和好评/中评/差评分布，可先核对一下再交付。

导出时会自动按门店过滤：如果抓取过程中顺手看过别的店，那家店的评论会被自动剔除，只保留本次目标门店的数据，无需手工清理。

04

导出的表格长什么样

CSV 共 9 列，与数据库的评论表字段一一对应：

列名含义示例
org_code机构编号（命令里指定的）080501
store_name门店名称丰裕(淮海店)
username评论人昵称狂暴的虎
review_date评论日期（相对时间已换算）2026-08-18
rating评分，0.0–5.0 星级
需要原始 0–50 星值时，导出加参数 --rating-scale raw		4.0
price_per_person人均消费（元）35
content评论正文生煎很不错，汤汁多……
sentiment情感分类：好评 / 中评 / 差评好评
store_feedback商家回复（多条用换行分隔，带回复时间时会标注日期）[商家回应] 非常感谢您的好评……
05

常见问题

中途想停下来怎么办？
直接按 Ctrl+C。已经抓到的评论都会保留，不会白抓。
一次没抓完，可以接着抓吗？
可以。重新运行一遍 capture 命令（同一个门店ID），数据会接在上次之后继续追加，导出时自动去重。
店的评论特别多（几万条），要抓很久怎么办？
在命令后加 --target 500（数字自定），抓够指定条数就自动停。开始抓取后注意看首屏显示的评论总数，量大就提前设置上限。
命令超时退出了，是什么问题？
说明 180 秒内没有打开评论列表页。检查是否进错了页面（必须停在评论列表页，不是推荐菜或其他页面），然后重新运行命令再打开一次。
跑完之后电脑上不了网了？
工具正常结束会自动恢复网络；极少数情况下（如强制关机）代理可能残留，重启电脑即可恢复。日常使用不需要手动改任何网络设置。
导出的表格里没有商家回复？
商家回复来自评论列表本身，只滚列表就能抓全。如果确实一条都没有，先去大众点评页面确认这家店是否有「商家回应」；导出结果会附 warning 提示。
